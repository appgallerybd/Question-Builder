# Multilingual Question Paper Generator

A production-ready foundation for a multilingual question paper authoring application supporting বাংলা, English, العربية and اردو.

## Current phase

**Phase 1 — Project Foundation** is complete.

### Foundation
- React + Vite + TypeScript
- Tailwind CSS v4
- Zustand-ready state architecture
- React Hook Form + Zod dependencies
- DOCX/PDF export dependencies
- Lucide icons
- Strict TypeScript
- Responsive application shell
- RTL/LTR-ready typography baseline

## Run locally

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
